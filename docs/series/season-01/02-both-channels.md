# Серия 2. Два канала, один выпуск
**Сезон:** «Фабрика Ани» · **уровень:** 2/4 · **наследует результат серии 1:** один утверждённый пост, инструменты написания и отправки разделены.

## Завязка — Аня отправляет материал в два места
**Аня → агент:** «Опубликуй утверждённый пост и в Telegram, и на сайте».
**Агент:** «Я могу отправить в Telegram. А для сайта — отдельное действие. С чего начнём?»
Аня: «Каждый раз две просьбы, два результата. А если одну отправку забудем?»
В кадре неизменный пост с датой **суббота 12:00**. Не показываем большой каталог интеграций.

## Сценарное действие
У агента три уже известных средства: `write_post`, `publish_telegram(post)`, `publish_website(post)`. Никаких новых способностей модель не получила.

**Первый проход, который видит зритель:** два отдельных действия «Отправить в Telegram», «Отправить на сайт». Если отправить только в Telegram, сайт остаётся «Ожидает», а Аня не знает, завершена ли задача «везде».
**Реплика Ани:** «Мне нужна одна команда на два канала, но текст один».

**Выбор зрителя:**
- «Попросить агента выполнить две публикации отдельно» — два ручных действия, незавершённая задача до второго результата.
- «Собрать одну команду „Опубликовать в оба“» — **композиция** двух уже существующих публикаторов. Новый общий шаг не пишет текст, только последовательно использует оба канала.

## Поворот и последствия
**Агент:** «Публикацию в два места можно собрать из двух действий. Вот результаты каждого».
Визуальная сцена показывает один документ и два выхода, причём оба имеют **отдельные статусы** (Telegram: доставлено в учебный outbox; сайт: готовая страница в учебном outbox). Два результата складываются под одной командой.
**Стоп-кадр:** `publish_both(post) = publish_telegram(post) + publish_website(post)`.
Реализация не обещает атомарной операции: Telegram может пройти, сайт — не пройти. Итог должен говорить «1 из 2» и предлагать повторить только неуспешную отправку, а не заново писать пост.

## Развязка
**Аня:** «Одно поручение, один пост. И я вижу, что получилось в каждом канале».
**Понятное имя:** «Собрали общее действие из двух маленьких» (*композиция*).
**Крючок к серии 3:** «Пришла третья площадка. Почему нашей команде „в оба“ опять нужно знать имена всех сервисов?»

## Постановка / тест
В одном кадре один утверждённый текст, два статуса публикации. Человек сначала видит незавершённость при выборе только одного. Затем собирает команду «в оба» и видит оба ответа без второй генерации. Отдельная ветка учебной ошибки сайта показывает **частичный** успех (не прятать сбой под общим «готово»). UI-only mock допустим для постановки, но должен маркировать симуляцию; при реализации предпочтителен существующий `assembleFactory({publisher:'both'})` и реальное построение двух browser artifacts. Нельзя утверждать о публикации в внешних сервисах.

**Проверка понимания:** зритель говорит: «Команда „в оба“ просто использует два готовых способа отправки; текст не меняется. Если сайт не прошёл, Telegram не надо публиковать заново».
