## Approved design / editorial brief
- Audience: experienced technically/marketing-savvy vibe coders; no coffee analogy, baby talk or framework catalogue.
- Useful action: identify where implementations are selected, how the scenario receives them, and prove which implementation was actually called.
- Start from the real existing runDigest parameter injection, not a fictional regression of the first lesson.
- Roles: MaterialSource, DraftWriter, Publisher. Objects are selected/created in assembly; the scenario uses the passed objects. Assembly arrows and runtime calls have distinct directions and explicit notes.
- Seven concise scenes develop the five approved beats: existing contracts; selection; passing objects; calling them; channel substitution; recording Publisher; sandbox.
- Primary block copy remains business rules. Technical details/code are in inspectors. Narration/captions/feedback written via statya, ux-copy and redaktura passes; informative headings, action labels, no invented external effects.
- Sandbox uses real deterministic adapters. Show the chosen assembly and recorded actual collect/write/publish calls; probe returns the captured Draft. Reject unknown configuration. Without approval publish must not be invoked.
- Sources: Martin Fowler injection.html; Mark Seemann CompositionRoot. DI does not require a container; DIP and DI are distinct.

## Architecture decisions
- Move factory contracts/pipeline/adapters to src/content-factory; both lessons depend on this application example, never on each other's story modules. No compatibility duplicate implementations.
- Native two-page Vite entry: index.html and di/index.html share main.tsx. App resolves / and /di[/] through a tiny lesson registry; unknown paths show an explicit not-found screen. No router dependency.
- Generic optional LessonLink[] is injected into StoryPlayer. It never imports either lesson; external vanya-arc link keeps _blank + noopener/noreferrer.
- Workspace deployment rule: add a dedicated ioc target in private cloudflare-deploy, same Worker/domain/account. Standard Vite dist replaces the obsolete app-local cf build config. Only ioc is deployed; no Fireplace/UI/Zero changes.
