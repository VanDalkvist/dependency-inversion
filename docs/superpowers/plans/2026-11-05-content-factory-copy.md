# Редактура объяснения DIP на примере фабрики контента

Запрос Вани: проверить остальные тексты и перейти к предметной области фабрики контента. Принятые заголовки и фокус на DIP сохраняются.

## Срез
- Сюжет: фабрика собирает материалы → убирает дубли → готовит AI-черновик → согласует → публикует выпуск. Текущий пример выпуска — дайджест для Telegram и сайта.
- Проверить пояснения, подписи, обратную связь, действия, инспектор схемы, учебные тексты публикаций, статусы плеера.
- Контракты MaterialSource / DraftWriter / Publisher, логика runDigest, данные состояния плеера и механика сцен не меняются.
- Не добавлять видео, автопостинг в настоящие сервисы, маркетинговые воронки или новые паттерны. Фабрика контента — предметная область, а не Factory Method.

## Проверка
- [x] RED: фабрика названа в начале; каждое объяснение DIP согласовано с реальными контрактами; учебные результаты не выдаются за реальные публикации.
- [x] Правка всех story-текстов и связанных интерфейсных формулировок; заготовленные материалы и выходные документы соответствуют фабрике контента.
- [x] Все заголовочные и поведенческие регрессии, тест запрета публикации без согласования, production build.
- [x] Chrome: сцены, интерактивный переворот, оба режима схемы, учебный выпуск и отсутствие публикаций при отказе; desktop/mobile.
- [x] Deploy на существующий ioc.vanya-arc.dev, публичная проверка и commit/push с сохранением постороннего WIP.

Редакторский диагноз: смешаны названия одного процесса; абстрактные фразы не показывают последствий; формулировки «локальная лента» и «артефакты» затемняют учебный статус результата. Решение: единый предметный сценарий, конкретные операции и отдельные направления вызовов/зависимости кода. Самостоятельного независимого ревью в этом срезе нет.

Результат: 38 тестов PASS, production build PASS. Публичный Chrome-прогон всех 9 сцен (1440px и 390px), 2 учебных документа при согласовании / 0 без него. JS и CSS публичного сайта совпадают с проверенной сборкой. Кнопка запуска вынесена в необязательный ExperimentDefinition.runLabel; универсальный плеер не содержит терминов фабрики.
