# DIP Interactive Film Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace the coffee analogy with a playable, interactive film explaining DIP through an evolving editorial pipeline.
**Architecture:** Generic StoryPlayer consumes application-owned StoryDefinition. DIP story implements that contract and is wired in App, never imported by player. A real deterministic in-memory digest pipeline consumes its own MaterialSource, DraftWriter and Publisher ports.
**Tech Stack:** Existing React 19, Motion 14, Vite 8, TypeScript, Vitest, Hearth & Wave.
**Spec:** User approval in thread thr_pq8ws4r4w8; this plan includes the bounded implementation contract below.

## Global Constraints
- Audience: experienced vibe coders, not necessarily professional programmers.
- Explain ownership and source dependency inversion, not a catalogue of other patterns.
- 9 scenes: direct script, expansion, insufficient extraction, publisher inversion, website addition, source inversion, editor inversion, execution vs dependency, sandbox.
- Play/Pause, previous/next, seek timeline, playback speed, keyboard, chapter navigation, selectable nodes.
- Required decisions pause playback; seeking never auto-resumes. Reduced motion and both themes.
- Preserve warm paper/charcoal, Manrope, micro radii, hairline surfaces; meaningful scene transitions only.
- No real AI calls, publications, credentials, automatic persistence, or third-party messages.
- Current app files are fully owned; unrelated workspace WIP is untouched.

## Review Focus
- Pause and gate cannot be bypassed by timer or stale callbacks.
- End, replay, seeking, invalid indices, speed changes are bounded.
- Mobile SVG remains inspectable; interactive nodes support keyboard.
- Simulation creates actual artifacts and preserves editorial selection under provider changes; denied approval writes nothing.
- Alternative story fixture renders without DIP-specific imports; no zombie coffee entry points.
