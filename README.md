# Независимая кофейня

Интерактивное объяснение инверсии зависимостей для непрограммистов.

React + Vite + Motion + локальная дизайн-система Hearth & Wave (`@vanya/ui`).

```sh
npm install
npm run dev -- --host 0.0.0.0
npm test
npm run build
```

Для локального пакета @vanya/ui рядом нужен checkout `../vanya-ui`.

## Короткий продуктовый контракт

Три шага: зависимость от детали → договор, заданный кофейней → сменяемые реализации. Пользователь меняет машины, готовит кофе, проверяет несовместимую реализацию и отвечает на вопрос. Стрелки показывают зависимость от требований, не поток кофе. Инверсия зависимостей не тождественна внедрению зависимостей.

## План и проверка

- [x] Сквозной каркас: загрузка React, токенов @vanya/ui и Motion.
- [x] Чистая модель совместимости и её тесты: смена реализации не меняет требования.
- [x] Анимированная сцена, три главы, рабочие действия и доступная мобильная версия.
- [x] Сборка, браузерные сценарии, светлая/тёмная темы, reduced motion.

Границы: статический клиент без API, секретов, аналитики, авторизации и БД. Модель не импортирует React или UI. UI использует модель. Точка сборки `src/main.tsx`.
